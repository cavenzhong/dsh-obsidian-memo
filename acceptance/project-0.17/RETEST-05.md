# DSH 定向复验：从河湾声音展 04 基线只跑 05

在新建的隔离 profile、测试 vault 和输出目录操作。不要改旧证据、个人仓库、模型默认提示词或生成结果。沿用首次验收的真实模型、预算，核对加载的是本次工作树（模型只返回 `overview / entry / summary`）。仅需 **一次** 真实 `addProject` 调用；无需重跑前四轮。

4. 不点确认，执行撤销；保存两份撤销后原文件，各自与操作前基线核对 SHA-256。返回基线、待验收、撤销后三组文件、真实摘要及运行结果；把模型内容质量、写入/撤销安全和未测的界面项分别报告。
