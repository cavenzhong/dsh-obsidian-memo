# README 配图

中文与英文 README 共用这套 0.17 截图。截图来自 0.17 实际插件界面，不含 Harness 外壳。浏览器载入本仓库的 `lib/client.js`，连接本地 Host，使用临时示例仓库「河湾声音展」。便签、插画和 AI 输出均为演示内容，未读取个人仓库或请求在线模型。

| 文件 | 场景 |
| --- | --- |
| `cover.png` | 便签墙与底部输入栏；外框和版本角标为文档排版，不属于 Harness 界面。 |
| `ai-comments.png` | 同一张便签的两条示例评论，展示四个视角入口以及评论正文。 |
| `project-drop.png` | 拖动便签，选择新建或补充已有项目。 |
| `project-review.png` | 写入后的变更摘要、查看／确认／撤销，以及源便签上的项目双链。 |
| `capture.png` | 展开快速记录栏后，输入标题、正文并添加两张参考图。 |
| `reader.png` | 钉住阅读面板，边看墙面边勾待办、读 AI 评论。 |
