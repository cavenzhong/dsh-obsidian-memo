# README 配图

中文 README 与 `README.en.md` 共用这三张图；英文页只改文案，不另存一套截图。

配图基于 v0.14.2 的 `lib/client.js` 实际 React 组件渲染，使用专为文档编写的演示笔记和示例插画，不含真实仓库数据。AI 评论文字为示例。

- `cover.png`：产品封面，包含实际便签墙界面。
- `capture.png`：快速记录输入栏，展示图文草稿与快捷键。
- `reader.png`：钉住的阅读面板，展示正文、任务清单与评论。

封面外围的排版和装饰用于产品展示；插件界面的布局、控件和字体沿用源码。截图不包含 DSH 外壳。
