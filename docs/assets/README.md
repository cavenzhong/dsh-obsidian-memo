# README 配图

中英文 README 各有一套 0.19.0 截图：中文在本目录，英文在 `en/`，使用相同的场景和文件名。浏览器加载本仓库构建出的 `lib/client.js`，连接本地插件 Host，操作临时示例仓库「河湾声音展」（River in Sound）。英文版启用插件的 English 界面，并使用英文示例便签、工作空间、评论角色与演示 AI 输出。只截插件界面，不含 Harness 外壳；封面的外框和版本角标是文档排版。便签、插画和 AI 输出均为演示内容，未使用个人仓库，也未调用在线模型。

| 文件 | 场景 |
| --- | --- |
| `cover.png` | 0.19 顶栏、工作空间标签、便签墙与底部快速记录栏。 |
| `workspace-picker.png` | 用顶栏的「＋」打开文件夹选择器，可搜索、新建或选择仓库里的文件夹。 |
| `workspace-move.png` | 把「沿河试听路线」（Riverside listening route）拖到主空间之外的「采样档案」（Field Archive），显示目标高亮和松手提示。 |
| `workspace-split.png` | 主空间（Main space）与采样档案（Field Archive）并排，展示双标签高亮、独立便签墙、分隔线和当前空间的快速记录提示。 |
| `capture.png` | 展开快速记录栏，输入标题、正文并添加两张参考图。 |
| `reader.png` | 钉住阅读面板，与便签墙并排展示任务清单和 AI 评论。 |
| `ai-comments.png` | 同一张便签的两条演示评论，以及四个视角入口。 |
