## 版本 0.16.3 变更摘要（2026-11-12）

- 重整浏览器代码：原约 6,200 行单文件拆成 `src/client/` 内按功能组织的 ES 模块；数据、编辑、设置、图片、拖拽、AI、筛选分页、布局、样式与文案各自维护。主面板缩至约 400 行，只组合状态和操作入口。
- Host 入口拆成 `lib/host/` 独立服务，明确配置、扫描单飞、写队列、图片缓存、任务与撤回 token 的状态所有权；保留 RPC、路径校验、内容版本、文件格式与现有交互行为。
- 使用固定版本的开发依赖 esbuild 生成并提交 `lib/client.js`，保持 Harness 单文件加载与零运行时依赖，直接安装无需构建。新增 `pnpm build`、`pnpm dev`、`pnpm build:check`，测试检查产物同步，打包自动构建，发布流程安装锁定依赖。
- 将大型前端、Host、Markdown 与配置测试按职责拆分，共用隔离的测试运行器；保留原有 354 项回归，新增模块依赖方向/无环/文件规模检查、服务隔离、写队列失败恢复、通知 hooks 与样式生命周期回归，共 362 项测试通过。
- 新增 [架构导航](ARCHITECTURE.md) 与根目录 AGENTS.md，提供功能到源码/测试的映射、模块协作边界和常用验证命令；同步中英文 README、开发指南、实现契约与已知问题位置，为后续大版本更新提供入口。

- 输入浮岛的 Tab 提示跟随标题并右对齐，空间不足自动置于下方；保留正文分割线。移除顶栏手动刷新，自动轮询和错误重试保留。

- 界面细节：便签使用普通箭头光标；标签底色和蒙层直接采用便签纸色，文字使用对应深色。关于区简化为一行 GitHub 链接与 by cavenzhong，「更多」移除下拉箭头。右侧操作条第一行依次为归档、到项目、删除、复制全文四个线图标与上方提示；第二行保留紫色的「在 Obsidian 打开」图标与文字。删除沿用 5 秒撤回。
- 补充配置迁移、外部 JSON 与冲突、目录创建与边界、跨字段历史、系统垃圾桶失败保护、设置标签与官方注册的回归测试；354 项测试全部通过。

## 版本 0.13.8 变更摘要

- **动态加载**：便签墙首屏只渲染 50 张，滚到接近底部自动补 50 张（IntersectionObserver，提前 320px）；墙底部有简约三点加载动画 + 「加载中…」淡字。排序/日期筛选变化回到首屏。数据仍是 Host 一次下发，分批的是渲染/DOM（评估：对几十张感知有限，300+ 张时明显降低首屏与滚动压力；没有引入虚拟列表的复杂度）。
