# 版本记录

[返回 README](../README.md) · [使用与开发指南](GUIDE.md)

以下保留各版本发布时的变更记录，当前功能以 README 与实现契约为准。

## 版本 0.19.1 变更摘要（2026-11-24）

- **修复移动、归档和改名导致双链失效的问题**：默认使用 Obsidian CLI，让 Obsidian 更新同一库内的引用，包括未挂载到便签墙的文件夹；撤销移动或归档时也同步更新。检测到仓库重叠、CLI 不可用或链接更新未开启时停止操作，不静默回退到直接移动。
- **仓库检测和首次配置引导**：「设置 → 文件夹」打开和换目录时自动检查，确认可用才显示绿勾。新库和已有库若未开启「自动更新内部链接」，一律显示黄色提示，指引在 Obsidian 的「设置 → 文件与链接」开启后重新检查。空文件夹可通过「在 Obsidian 中设为库…」登记，也可以在 Obsidian 中新建库；插件不改写 Obsidian 配置。
- **仍可管理普通 Markdown 文件夹**：无需安装 Obsidian。选择「文件夹管理」后不做 CLI 检测，并明确提示移动、归档和改名不会修复双链。升级后若使用的是普通文件夹，请在「设置 → 文件夹 → 操作引擎」手动选择此模式并保存；阅读、新建和只改正文不依赖 CLI。
- **设置与兼容性**：移除设置页重复的子文件夹开关，保留顶栏过滤和默认工作空间目录选择；修复评论撤回请求附带文件路径时可能卡住的问题。

## 版本 0.19.0 变更摘要（2026-11-24）

- **双工作空间**：工作空间栏最右侧的分屏图标与 `Cmd+;` 切换单双屏。启用时只有图标变紫、无背景色，两个空间并排，点第三个只替换当前有焦点的一侧；图标灭时只保留并点亮当前空间。两侧独立滚动，淡色的细分隔线位于快速记录浮岛下面，可拖动调宽；快速记录落到当前侧。状态与宽度按仓库保存在本地。
- **快捷切换**：按住 Cmd，在前九个工作空间标签右侧显示 `⌘1–⌘9`，按数字切换对应工作空间；分屏图标旁也会显示「锁定／取消锁定视图 `⌘;`」。
- **阅读定位**：打开右侧抽屉后，按重排后的实际列数把点开的便签行缓动滚到所属视口第一排，停稳后再以 1px 紫色描边提示约 0.5 秒并渐隐。
- **便签外观**：悬停时便签细边变白、保留投影，移开后恢复原色；工作空间色板在纸白后增加浅灰。
- **列表编辑与标签排序**：多选列表项可用 Cmd/Ctrl+L 批量切换标记，按住 Cmd/Ctrl 时显示对应提示。阅读态拖动圆点或待办接近正文上下边缘时会自动加速滚动。鼠标按住自定义标签即可横拖排序，无需长按；触屏仍用长按排序、短滑浏览。标签溢出时可拖到边缘继续滚动。
- **文档与验证**：中英文 README 在工作空间之后新增双视图配图和用法，原有截图用 0.19.0 重新拍摄；安装、构建与 609 项回归通过，并用临时示例仓库复核双视图焦点、第三标签替换、独立滚动、宽度恢复和原有记录／阅读／移动／项目流程。

## 版本 0.18.7 变更摘要（2026-11-23）

- **MD 附件不再携带评论**：发送 MD 附件时，上传的是临时 `.md` 副本。插件会移除便签解析器识别出的评论 callout，保留 frontmatter、标题、代码围栏、普通引用和其它正文；原便签与评论均不修改。
- **复用空白对话更可靠**：兼容 DSH 0.2.2 的 `input.removeAttachment` 返回 `void`，改以附件快照确认清理结果，避免复用带旧附件的空白会话时误报「无法清空新对话的旧附件」。
- **共享规则与无障碍**：评论 callout/引用行识别收敛到 `src/shared/markdown.js`，Host 解析与附件副本清理共用同一规则；发送菜单的 `aria-label` 按当前场景显示具体标题。
- 同步中英文 README、架构导航与实现契约；`pnpm build` 更新 `lib/client.js`，`pnpm test` 590 项全部通过。

## 版本 0.18.6 变更摘要（2026-11-23）

- **发送到 DeepSeek**：右侧阅读抽屉操作条第 5 个图标（复制之后）、卡片悬停菜单（DeepSeek 在复制左侧）和底部拖拽操作栏新增发送入口。所有入口共用一个浮动菜单：先选「原文 + 标题」或「MD 附件」，再选 DSH 默认工作区或用户已有工作区。
- **选中文字右键**：取消便签卡片右键菜单；在插件内选中文字后右键，弹出「复制选中的文字 / 发送到 DeepSeek」，取代原生右键菜单。发送时使用共享工作区菜单，不出现附件形式。
- **DeepSeek 图标统一灰色**：卡片、阅读抽屉、拖拽栏、发送菜单与设置里的鲸鱼 mark 不再使用品牌蓝，改为与界面文字一致的灰色；插件强调色仍用现有紫色。
- **拖拽反馈与文案**：拖到浮岛时 DeepSeek 使用原项目的蓝色蒙版，到项目改为紫色蒙版；操作格文字由 DeepSeek 改为「到DeepSeek」。
- **两种发送形式**：原文模式把标题作为第一段、正文接在后面，不带 `.md`；MD 附件模式读取原始 `.md` 文件并通过 DSH 文件上传作为草稿附件，消息文字只带标题。两种都不附现有 AI 评论，不改原文件。
- **新对话加载**：原文模式通过 `uiWorkspace.startSession(...)` 把内容放进未发送输入框；附件模式通过 `uiWorkspace.openWorkspace(...)` 在打开前把 `.md` 上传为草稿附件并设置标题文字。页面同时跳转，用户按 Enter 才真正发送。
- **设置**：便签页「便签标题」之后新增「发送到 DeepSeek」。默认每次弹菜单；勾选「不弹出选择菜单，按下面的设置直接发送」后，可固定默认工作区和发送形式。配置写入 `config.json` 的 `deepseekSend`，旧配置自动补默认值；工作区 id 失效时按路径回退，再回退默认/当前工作区。
- **侧栏折叠自适应**：Client 通过 `sidebar.footer.action` 的 `wide` 上报宿主侧栏状态；展开时 macOS 顶栏顶部净空从约 58px 收窄到 34px，折叠时保持原距离，避免标题与菜单上方出现多余空白。
- Host 新增只读 `noteFile` RPC，用于附件模式读取原始 `.md`；Client 新增 `src/shared/send.js`、`src/client/deepseek/`、`src/client/sidebar-state.js`、设置块与完整回归覆盖；`pnpm build` 生成 `lib/client.js`，`pnpm test` 589 项全部通过。

## 版本 0.18.0 变更摘要（2026-11-23）

- **工作空间范围扩到整个仓库**：第二个标签行取代原目录路径。第一个标签更名为「主空间」，就是设置里的**默认工作空间**（原「便签文件夹」改名）；其余标签可以挂载仓库内任意可见目录，甚至位于默认工作空间之外或它的父级。Client 在每次 `state` 上报已挂载根，Host 在默认工作空间之外补扫这些目录；未挂载的目录不会出现在墙上。
- **多根扫描**：Host 校验仓库相对根（拒绝 `..`/隐藏/绝对/越界/缺失，最多 24 个），每个文件归入第一个命中的根；`tag`/颜色按所属根计算，`relPath` 仍相对仓库。根集合变化会改变 revision 并重扫；写操作沿用最近一次 `state` 的根。主空间关闭「显示子文件夹」时只显示默认工作空间顶层，自定义工作空间始终含子树。
- **添加与删除**：加号复用设置里的 `VaultFolderPicker`（搜索 / 最近 / 新建 / 系统选择），列表隐藏仓库根、默认工作空间和已挂载目录；其余仓库内可见目录都可添加。自定义标签右键「删除」（不动文件夹，5 秒内可撤销）；主空间不可删除、不可拖动。
- **排序**：长按标签约 380ms 进入拖动，其他标签间显示紫色插入线，松手保存顺序并补扫；普通点击与横向滚动不受影响。标签过多时收进「…」，菜单列出全部空间并勾选当前项。
- **拖拽迁移**：卡片拖到任意标签即可把便签移进该目录；所有挂载工作空间都接收便签（不再有「目录外只读」）。松手调用 Host `moveNote`（独占移动、同名自动加 ` (2)`、运行中的 AI 任务拒绝），toast 6 秒内可撤销（`undoMove`）。
- **新建与边界**：快速记录把当前空间的绝对 `targetDir` 传给 `createNote`（主空间 = 默认工作空间，自定义 = 该目录）；`assertNotePath` 从默认工作空间扩大到整个仓库（拒绝隐藏目录/非 md/越界符号链接），迁移、归档、删除、评论和项目都能处理挂载空间的便签。归档 mapped 模式对默认空间沿用原结构，对其它空间按仓库结构映射；当前目录模式每个扫描根跳过同名归档文件夹，mapped 模式整体排除归档根。
- **颜色**：自定义空间右键菜单有 8 个纸色圆点（新增空间默认从未占用颜色中随机分配）；选中后该空间内所有卡片统一使用对应浅/深纸色，阅读抽屉的便签胶囊沿用；主空间仍按文件夹配色。菜单点到菜单外任意位置都会立即收起。
- **评论区**：零评论时自动折叠（按钮禁用、不再显示「暂无评论」占位）；出现评论后才恢复用户保存的折叠状态与拖拽高度。
- **布局与弹层**：标签栏与标题行间距收紧；添加弹层和右键菜单都夹在标签栏/面板范围内（修复从左侧「＋」打开时被 DSH 左侧栏遮掉），面板较矮时自动限高。已挂载目录、默认工作空间与仓库根不再出现在添加列表；选择被拒绝时弹层保持展开并在列表上方说明。切换空间后便签墙回到顶部。日期菜单增加移出缓冲与透明桥接区；卡片操作区渐变不再截获鼠标。
- **安全边界加固**：归档树不能通过挂载根、子目录或仓库内符号链接重新进入活动墙；工作空间列表、系统选择、新建与迁移统一拒绝当前归档目录，通用设置仍可正常选择归档路径。撤销归档/迁移会核对目标文件版本，目标被替换或修改时拒绝撤销；`moveNote` 并入便签写锁，避免与保存并发。
- **界面语言**：设置 →「管理与关于」可跟随 Harness 或固定中文/英文，立即生效且只记在当前浏览器；Host 常见诊断文案在英文界面下提供翻译，未知底层错误保留原文。项目页增加 Beta 提示，并同步英文截图与双语文档。
- Host 新增 `state.workspaces`、`createNote.targetDir`、`moveNote` / `undoMove`；Client 新增 `src/client/panel/workspaces.js`、`use-workspaces.js`、`use-workspace-reorder.js`、`workspace-bar.js`、界面语言与错误诊断模块，并补齐对应回归测试。`pnpm test` 536 项通过。

## 版本 0.17.3 变更摘要（2026-11-22）

> 本版一并纳入上一轮工作树里的归档改造；0.17.0 的记录保持发布时的内容。

- **归档方式重构**：设置 →「便签」新增归档专栏，可在「当前目录」与「指定目录并保留结构」之间选择。当前目录模式把便签移入其所在目录下可自定义名称的文件夹（默认「归档」）；指定目录模式把便签移入选定根目录，并按原便签目录结构创建子文件夹。归档根目录必须在仓库内、不能是隐藏目录，也不能与便签目录重叠。
- 拖拽归档不再弹出目标菜单或停在待选状态：拖到「归档」按钮松手立即移动，跟随预览的提示会显示实际目标；阅读抽屉的归档按钮也直接执行。撤销 toast 保留。
- 当前目录模式下扫描会跳过同名归档文件夹，归档后的便签不再出现在活动便签墙；指定目录模式按便签的仓库相对目录映射，同名文件自动加序号。旧 `archiveTargets` 配置不再使用，升级后默认按当前目录的「归档」文件夹归档；需要指定目录时在设置里重新选择，原目标不会自动迁移。
- **顶栏拖动与单击兼容**：macOS 桌面版改用指针事件 + `window.moveTo` 移动窗口（位移超过 3px 才进入拖动）。标题「Obsidian MEMO」、版本、目录、留白和按钮间隙现在都能按住拖动整个 DSH；同一区域单击（位移 < 3px）收起未锁定的右侧抽屉，拖动后松手不误关。按钮、菜单和输入框不参与拖动。
- Web GUI 保持单击收起抽屉；Windows 继续使用 app-region 拖动。移除旧的标题上方点击条与「标题 no-drag / 空白 drag」相邻分区。
- 文档与版本号同步到 0.17.3：README 安装确认版本、ARCHITECTURE、CONTRACT、GUIDE、KNOWN_ISSUES；`pnpm test` 503 项通过。

## 版本 0.17.0 变更摘要（2026-11-21）

- Project 从“一次生成的结构化索引”改为“持续修订的活文档”：项目仍是 `<项目名>-项目.md`，源便签不移动，只写一个可配置的 `PROJECT` 双链。
- 文档固定为 `## 当前概况` 与 `## 进展记录`：概况可重写，历史只追加；用户手写的独立二级章节、YAML/BOM、前言与旧记录由 Host 逐字节保留。
- 模型写作协议改为只返回 `{overview, entry, summary}`，不再要求模型复写受保护文字；Host 负责章节定位、旧布局迁移、行尾风格和写入事务。这样模型无法通过“少抄一段手记”破坏项目，也不会因复写失败而整次拒写。
