# 使用与开发指南

[返回 README](../README.md) · [版本记录](CHANGELOG.md)

本页保留完整的操作说明、文件行为与开发细节。想先了解产品，请看 README。

把 Obsidian 的「进行时」文件夹，变成 DSH 左侧栏入口的一面淡色便签墙（dsh-obsidian-memo）：快速新建、阅读/编辑、卡片内图片预览、四种性格的 AI 评论、归档、开档、一键在 Obsidian 打开，全在一个面板里完成。读写 md 文件与新建图片附件，Obsidian 仍是唯一的数据主人。

## 它长什么样

```
┌─ DSH 侧栏 ─┐┌─────── Obsidian MEMO by caven v0.15.0 ──────────┐
│ 会话       ││ 120 张便签      [日期][子文件夹][排序][刷新][⚙]       │
│ 插件       ││ ┌──────────┐ ┌──────────┐ ┌───────────┐        │
│ 📌 便签    ││ │WORKING_NOW│ │ 无 tag   │ │🚧长期     │        │
│ 自动化任务 ││ │宋体加粗标题│ │标题      │ │标题       │        │
│            ││ │浅一档正文  │ │正文      │ │正文       │        │
│            ││ │ 评论…     │ │          │ │评论…      │        │
│            ││ │[图][图]＋3│ │          │ │[图][图]   │        │
│            ││ │😈✨🧭😇 | 复制 ↗ │ └──────────┘        │        │
└────────────┘└─────────────────────────────────────────────────┘
```

- **淡色便签**：按 tag（相对便签目录的第一层子文件夹）稳定分配颜色，无 tag 用纸白；0.13 把日间纸色整体往白里调（`#FDFAF4` 系）。开启暗色主题时自动换成同色相的深色纸与提亮墨色。
- **标题 = md 文件名**（去掉 `.md`）：卡片和阅读视图都用文件名；第一段属于正文。标题用宋体加粗（Songti SC 栈）。
- **更轻的正文**：正文与卡片摘要统一 80% 不透明度。
- **署名**：面板标题后显示淡色 `by caven v<版本>`。运行时版本只取 `package.json`，由 Host 下发；Client 和 locale 不再保留需要同步的版本常量，收到版本前只显示 `by caven`。
- **卡片图片预览**：正文里的图片（`![](…)` / `![[附件]]`）不需要进阅读模式，直接在卡片**左下角、贴住卡片底部**以 64×64 正方形缩略图预览；最多 3 张，超出的显示淡色 `＋N`。缩略图懒加载（并发 ≤3）、失败静默占位、按内存预算缓存，卡片高度仍是 208px（有图时只压缩摘要/评论的行数，标题不压缩）。**只要卡片操作菜单出现（悬停/聚焦整张卡片），图片预览就统一隐藏**，移出后恢复——不再区分鼠标是否停在 emoji 上。
- **阅读**：单击卡片从右侧推出约 1/3 宽的面板看全文（正文块 + PROJECTS），面板宽度可拖拽调整；评论固定贴在面板下方的独立区域，正文怎么滚都不影响。抽屉标题分割线下方有**操作条**：左边一排 AI emoji 评论（悬停显文字标题），右边「归档 / 到项目」——便签卡片在阅读时不显示操作菜单，操作都收在这里（锁定/未锁定都一样）。
- **编辑**：在抽屉里双击标题或正文进入编辑态；标题用多行输入框完整换行显示（不用横向滚到文件名尾部），正文编辑原始 Markdown；点一次「保存」同时保存标题与正文，重名时拒绝覆盖。
- **锁定面板**：抽屉右上角有锁定按钮（0.13.9 起图标从锁改成**图钉**）。锁定后便签变成真正的右侧面板，与便签墙左右并排、不再互相遮挡；**锁定态不显示关闭按钮**（只留锁定/解锁，Esc 可关），解锁后关闭按钮恢复。锁定状态记住。**锁定面板再进入时不隐藏**：切换面板/重进会恢复上次打开的那篇便签；若它不在当前日期筛选里（或已被归档/改名），自动打开当前筛选排序后的第一篇。
- **阅读勾选**：阅读模式下可以直接勾选或取消任务项，写回原 Markdown 的 `[ ]` / `[x]`，保留原换行和 frontmatter。若内容已被外部修改，会提示刷新后再操作。
- **图片与分界线**：阅读模式显示 Markdown 分界线、`![说明](https://…)`、相对路径图片和 `![[附件]]`。本地图片先从便签相对路径、仓库相对路径查找，Obsidian 裸附件名还会在仓库内查找；重名附件需写完整路径。
- **子文件夹开关**：顶栏的 folder-tree 图标控制是否显示子文件夹里的便签（默认显示）；关闭后墙只保留便签目录顶层的 md。状态写进设置，重启后保持。所有顶栏 icon 的选中态统一为**浅紫底 + 紫色图标**（日期筛选/子文件夹/锁定/排序/设置）。
- **排序**：默认按文件创建时间（新→旧，菜单第一项）；右上角排序按钮可切换创建时间正序、最近修改、文件名。
- **日期筛选开关（0.14）**：顶栏操作区第一个日历图标，点亮按当前范围筛选，熄灭显示全部；与子文件夹图标等宽，不再显示小三角。鼠标悬停显示今天／3 天／本周／本月菜单，移出关闭；键盘可用 ↓ 打开菜单，Esc 关闭。菜单保留「日期截止按真实时间」选项，范围与开关状态继续记住。
- **底部快速记录（0.14）**：透明磨砂胶囊浮在便签墙下方，背后以白色到透明的渐变隔开卡片；深色主题自动换成深色渐变。输入想法作为当前便签目录中新 `.md` 的文件名，按 Enter 创建；标题不会重复写入正文。面板空白处（无焦点）按 Tab 先聚焦标题，按钮/卡片/输入框上保持原生 Tab 顺序；标题内再按 Tab 展开带分割线的正文区，文字更小、更淡，并自动聚焦；正文按 Shift+Tab 返回标题修改，保留正文草稿，再按 Tab 可回到正文；正文可正常换行，⌘／Ctrl + Enter 创建。未展开时仅显示淡色 `Tab 补充正文` 提示；正文删空后自动收起为标题态（空正文 Backspace 或失焦也会收起，Esc 退出输入焦点）。正文区右下角显示淡色 `⌘ Enter 提交` 提示，焦点描边更清晰。重名、文件名过长或提交失败时保留草稿与图片，成功才清空。新建时沿用 Obsidian Default Template 为当前文件夹配置的模板 meta（`{{date}}`/`{{time}}`/`{{title}}` 变量按插件语义替换；模板配置损坏或不可读时按无模板新建），带正文或图片也会保留。阅读视图保留有序列表数字与无序列表圆点。
- **拖拽与删除（0.15）**：拖动卡片时输入岛切换为「归档 / 到项目 / 删除」三列操作栏，输入岛暂时隐藏。拖到归档后可选已配置目录，拖到项目会打开项目名对话框，删除在放手时执行；原位置保留空虚线框，拖动卡片的宽高均缩为原来的 1/3，实色动作提示固定在预览上方且层级更高，底部渐变随目标变色。卡片菜单在 AI 评论下方仅保留「复制 / 在 Obsidian 打开」，归档与到项目从拖拽栏或阅读面板进入；聚焦卡片或阅读面板时按 ⌘／Ctrl + Backspace 可删除。md 与独占图片成组进入库内 `.trash/MEMO-…` 文件夹，5 秒内撤回；共享图片保留，冲突时拒绝覆盖。到期后文件保留，可按组内 `restore.json` 的原路径手动移回，不自动清空；已有回收文件不会被清理。macOS Finder 按 `⌘ + Shift + .` 可显示隐藏文件夹。
- **归档目录待选择（0.15）**：拖拽缩略卡片带柔和阴影，动作提示在其上方居中。目录菜单固定在底部归档区上方，并带淡阴影。在归档主区放手后，预览停在归档图标与文字的位置，图标文字暂时隐藏；点击目录完成归档。点击外部、焦点移出、窗口失焦或 Esc 回到原位，Enter 回落后聚焦输入岛。
- **输入岛（0.15）**：Enter 统一聚焦输入岛，输入岛内输入和右侧正文编辑保留原行为，输入法组合态不拦截；卡片悬停或聚焦时也不会再打开详情，Esc 退出焦点。标题自动折行显示全文。向下超过一屏后上方出现圆形 ↑ 返回顶部。浮动或钉住面板都不遮挡输入岛与拖拽栏。
- **新建图片（0.14）**：在输入栏粘贴或拖入图片，或点左侧加号多选 PNG／JPEG／GIF／WebP；左侧正方形预览默认叠放，悬停或键盘聚焦后展开，停留 600ms 在上方显示最大约 260×220px 的完整图浮窗，可逐张移除。最多 8 张，保存后的单张上限 8 MB、合计 16 MB。在设置的「图片处理 → 图片文件夹」可手填或选择仓库内目录，相对路径按仓库解析，不存在时自动创建；不能选仓库内以 `.` 开头的隐藏目录（Obsidian 不索引）；留空仍保存在便签目录的 `_attachments/`。目录调整仅影响之后保存的图片。Markdown 使用仓库相对图片 wikilink，便签归档后仍能在 Obsidian 找到图片。
- **图片处理（0.14）**：设置里独立的「图片处理」专栏，默认勾选自动压缩为静态 WebP，质量 **70**、最大边长 **2048px**。可调整质量 1–100、最大边长 256–8192px；按比例缩小、不放大小图。取消勾选则保留原始字节、格式及动图。参数在创建时生效，修改设置后待提交的图片也按新参数处理。压缩前单张最多 32 MB、合计 64 MB；压缩完成后按上述保存上限检查。压缩失败保留草稿并提示原因。

- **AI 评论（0.13）**：卡片 hover 后，**所有 emoji 预设平铺在操作区第一行**（不折叠）；鼠标悬停某一枚时，在它上方浮出文字标题告诉你这个 emoji 是什么（如「毒舌」）。点击后后台用默认模型生成，以 Obsidian callout 追加到 md 末尾，卡片上同步显示。若这张便签已有同款评论，会先问「要再生成一条吗？」。分割线下方是「复制 / 在 Obsidian 打开」。
- **四个 AI 人格预设**：
  - 😈 **毒舌**：尖锐黑色幽默，要妙、像金句，但不为刻薄而刻薄；专业问题玩笑后会提醒找专业人士；写作类则切换成大哥口吻给一句真正有用的话。
  - ✨ **另一面**：从一个你完全没想过的角度切入，再回到人本身，说中情绪但不空洞共情。
  - 🧭 **落地**：务实判断，惜字如金——一句话结论 → 2–3 条证据链（标明推测）→ 最省力的下一步与验证信号。
  - 😇 **真心话**：贴心伙伴，接住状态、指出你做对的一个小地方，给一句不带压力的鼓励和一个轻起手。
  - 旧版本的 4 个默认预设（洞察/延伸/风险/下一步）如果原样没改过，会自动迁移成这 4 个；你改过的预设不动。
- **归档**：选一个归档目录，文件移动过去；顶部小浮窗 6 秒内可「撤销」，不挡其他操作。
- **开档**：输入项目名，在开档目录下建 `<项目名>/<项目名>.md`，用可编辑的建档提示词生成结构化文档（诉求 / 现状与已知 / 调查与线索 / 下一步 / 待确认），并把链接写回源便签的 `PROJECTS`。
- **在 Obsidian 打开（0.13.8 / 0.13.9 微调）**：卡片操作行「复制」的**右侧**（同一行、右对齐）是「在 Obsidian 打开」：一枚转发 icon + **紫色高亮**加粗文字；右侧面板的操作条最右也有一枚同款按钮，面板较窄时操作条会换行（归档 / 开档在上，它在下一行）。点击后由 **Host** 调系统打开器打开 `obsidian://open?path=<便签绝对路径>`（macOS `open` / Windows `start` / Linux `xdg-open`）；DSH 外壳只放行 http(s) 外链，所以自定义协议必须走 Host。只允许打开仓库内已存在的文件；没装 Obsidian / 没有打开器时用 toast 报原因，不会碰任何文件。
- **0.13.9 小细节**：卡片没有正文时**不再显示「（暂无正文）」占位**；Obsidian 行尾 / 段中的 block id（`^qa-daily-preview-1e5t8lm` 这种）在正文与摘要里隐藏，且**只去掉锚点本身、不影响锚点后面的文字**；顶栏「Obsidian MEMO」标题区域（含下方的目录小字）在 **DSH 桌面版**里可以直接按住拖动整个窗口（Web GUI 里浏览器会忽略该行为），右侧按钮区仍然正常点击。
- **动态加载（0.13.8）**：便签墙**首屏只渲染 50 张**，滚到接近底部（提前约 320px）自动补下一批 50 张；补批时墙底部出现**简约三点加载动画 + 「加载中…」淡字**。排序/日期筛选变化会回到首屏 50 张。数据仍是 Host 一次 `state` 下发（几十 KB），这里分批的是**渲染 / DOM**，不是网络请求——对几十张的库感知很小，几百张以上时明显降低首屏渲染与滚动压力（详见「性能与后台开销」）。

## 安装

```bash
# 在 DSH 里用工具安装（等价于 Plugins 页的“安装”）：
#   plugin_manager  action=install_bundle  target=link:/绝对路径/dsh-obsidian-memo
```

安装后左侧栏末尾出现便签图标。首次点击面板会提示去设置里选目录。

### 可选：改代码即时生效（开发用）

在 `~/.dsh/profiles/<profile>/cordis.patch.yml` 的 `hmr` 条目里加上本插件目录：

```yaml
- id: hmr
  name: "@deepseek-ai/dsh-hmr"
  config:
    root:
      - "."
      - /absolute/path/to/dsh-obsidian-memo
```

之后改 `lib/*.js` 会自动重载（Host 与浏览器半都生效）。

## 首次配置

面板右上角齿轮 → 设置抽屉：

| 字段 | 说明 |
|---|---|
| 仓库根目录 | Obsidian 仓库绝对路径（如 `…/Documents/2024仓库`） |
| 便签目录 | 想展示的主目录（如 `⛳️进行时&未整理`），必须是仓库子目录 |
| 开档目录 | 新的项目文件夹建在这里（如 `✅DONE_PROJECT已完成/projects`） |
| 归档目录 | 可加多个：名称 + 路径；归档按钮会弹这些目标 |
| 图片处理 / 图片文件夹 | 自动压缩为 WebP（默认勾选），质量 1–100（默认 70），最大边长 256–8192px（默认 2048）；取消勾选保留原图。图片文件夹保存新建图片，留空 = 便签目录的 `_attachments/`，必须是仓库内目录且不能是以 `.` 开头的隐藏目录 |
| Emoji 与提示词 | 每枚 emoji 占一行：emoji 字形 + 名称 + **callout 样式按钮** + 删除；样式按钮直接写「callout样式-引用」，点开是 13 个样式菜单、当前项打勾（0.13.8 重排，名称输入占剩余宽度）；提示词在下一行；可增删（默认 4 个新预设） |
| AI 预算 | 每枚 emoji 行内一个下拉：**低 / 中 / 高 / 自定义**（低 = 不思考·2048、中 = 低思考·4096、高 = 高思考·8192 tokens，默认高）。选「自定义」时再露出「思考档位 + 输出上限」两个字段；建档提示词下方同款控件，控制开档。 |
| 建档提示词 | 「开档」时生成结构化文档的提示词 |

设置保存在插件自己的 `data/settings.json`，不写 Obsidian 仓库，也不写 DSH profile 配置。目录字段用系统目录选择器（macOS 原生对话框，可直接选 iCloud 里的 Obsidian 库）；也可以手动输入路径（支持 `~`）。

## 它怎么碰你的文件

- **只写配置目录内的 Markdown 和新建图片附件**：便签目录、归档目录、开档目录、图片文件夹的用户路径与真实位置都必须落在仓库内；图片文件夹不能是隐藏目录；目录符号链接也要校验，新建路径检查最近的已有父目录。
- **frontmatter 原样保留**：渲染永远丢弃 meta；只有「开档写回 PROJECTS」这一处会改 frontmatter，且只改 `PROJECTS` 一个键，已有非空值时不覆盖。
- **原子写**：已有文件先写临时文件再 `rename`；新建便签先保存附件，再以独占硬链接发布完整 Markdown，拒绝覆盖同名文件。发布失败会清理本次附件与临时文件。
- **保存与评论**：保存只替换 frontmatter 之后的正文；评论追加在文末，都是纯文本拼接，不重排 frontmatter、不规范化格式。
- **与 Obsidian 并发**：编辑保存带有打开时的内容版本，若期间被 Obsidian、AI 评论或其他编辑改变，会拒绝保存并保留草稿。没有跨进程文件锁；版本检查和写盘之间的极短外部写入竞争仍可能发生。
- **不渲染 meta**：卡片标题取 md 文件名，文件内容作为正文，callout 作为评论；行尾 block id（`^qa-daily-preview-…`）不显示，且不影响锚点后面的文字与行内代码里的 `^`。

## AI 评论与开档

- 用的是 DSH 当前默认模型（`agentDefaultModel`），通过 Host 的 `ctx.llm` 调用：**不占用任何会话、不写对话日志**。
- 生成是异步 job：点击后立即返回，面板显示「正在写评论…」，完成后写入 md 并自动刷新；失败会在 toast 里给出原因。
- **AI 预算（0.13）**：DeepSeek 的 `max_tokens` 是总输出预算，思考 token 也算。默认「高」档（`high` / 8192）就是给思考留足余量；如果模型把预算全用在思考上、正文没写出来，会弹一条带「去设置 / 知道了」的提示，点「去设置」直接打开设置抽屉调档。同理，撞上上限但写出了半截内容时也会提示（内容照常写入）。
- 评论 callout 形如：

  ```markdown
  > [!quote] 😈 毒舌 · 2026-11-04 10:30
  > 这条想法真正的钩子在……
  ```

- 开档生成的项目文档带 frontmatter：

  ```markdown
  ---
  ```

## 技术架构

- **Host 半**：`lib/index.js` 组合 RPC 与业务；`files.js` 统一真实路径边界、内容版本与原子写入，`capture.js` 负责新建便签与附件；`notes.js` / `scan.js` / `settings.js` / `ai.js` / `obsidian.js` 分别负责解析、扫描缓存、设置、模型和系统打开。
- **通道**：Host 在 web server 上注册包内已认证 RPC 前缀路由 `/sticky-notes`，复用 client-connection 的 RPC 信封协议（Client 仍用 `ctx.connection.rpc.call('/sticky-notes', endpoint, payload)`），认证复用 `ctx.connection.requestRejection`。Web GUI 与桌面 App 外壳都走同一条已认证通道，不新开端口、不需要额外的 CSRF 防护。
- **目录选择**：统一使用系统选择器 `pickDirectory`，也可手动输入路径；已移除没有界面调用的目录浏览 RPC。
- **Client 半**（`lib/client.js`）：保留单文件发布、零构建步骤。内部由 `useNotesData` 管请求与轮询、`useNoteEditor` 管抽屉草稿与保存、`useSettingsDraft` 管设置草稿；面板组合布局和操作。所有 state 请求统一按代次接收，迟到响应不能覆盖新状态，未变化卡片复用对象。
- **不注册模型工具、不注入提示词**：除用户主动点评论/开档外，不产生任何模型调用与会话成本。
- **已知问题与暂缓项**：见 [已知问题](KNOWN_ISSUES.md)（v0.15.0 基准，含触发条件与建议修法）。

## 性能与后台开销

- Host 端 `state` 轮询在真实库（97 篇）实测热响应 3.5–6.5ms、2.4KB；冷启动约 67KB。扫描按 mtime 缓存，内容没变不重读。
- **空闲轮询会自适应退避**：4s → 8s → 12s → … 最长 30s；有变化或你主动刷新/评论/保存时立即回到 4s。面板不可见（切到别的面板/窗口隐藏）时暂停请求，约 15s 才探测一次。
- 便签卡片做了 memo：轮询拿到「没有变化」时面板不会整墙重渲染；有变化时只重渲染变化的卡片。
- **便签墙分批渲染（0.13.8）**：首屏 50 张，触底补 50 张。Host 下发的 notes 只有几 KB～几十 KB（97 篇热响应 2.4KB），所以这一层不减少网络，只减少首屏 DOM/布局与 React 渲染量；没有引入虚拟列表（不卸载已渲染卡片），复杂度最低。120 张左右收益有限，300+ 张时更明显。
- 卡片缩略图：进入视口才加载、同时最多 3 个请求、按约 24MB 内存预算做 LRU，避免一次涌入大量 base64 卡住主线程。
- Host 端对同一设置指纹的并发扫描做了单飞（single-flight），附件名查找有负缓存，避免重复全库遍历。
- 如果仍然遇到 DSH 整体卡死，请先看：① 是否正在大量新增/同步笔记（iCloud 文件下载会拖慢一切）；② 卡死时 CPU 大户是 DSH 的哪个进程；③ 把插件禁用后是否还复现——这能区分「插件开销」与「DSH 自身/HMR」问题。

## 已知限制

- 不做全文搜索、拖拽排序、批量选择。
- **「在 Obsidian 打开」依赖本机 Obsidian**（macOS `open` / Windows `start` / Linux `xdg-open` 调 `obsidian://open?path=…`）：未安装或未注册协议时会 toast 失败；只对仓库内已存在的文件生效；这个动作不会写入任何内容，打开后由 Obsidian 自己读取文件。
- 编辑态保存是显式按钮（或 Cmd/Ctrl+S），退出编辑态会丢弃未保存修改。
- 归档撤销窗口 6 秒（token 服务端保留 10 分钟）；撤销前若原位置已有同名文件则拒绝恢复。
- 面板以轮询感知外部修改，不是实时监听；空闲时按 4–30 秒间隔检查外部变化，也可以手动刷新。
- 手动改 `package.json` 或依赖不会被 HMR 检测；改 `lib/*.js` 需要配置 hmr root 才会即时生效。
- 本地图片限仓库内的 PNG/JPEG/GIF/WebP/SVG/AVIF，单张不超过 8 MB；卡片缩略图只加载 ≤1.5 MB 的图片（超出的卡片上显示淡占位，进阅读模式仍可看）。卡片预览只覆盖正文图片，不覆盖 callout/列表内的图片。
- 不读取仓库外的符号链接目标；网络图片由浏览器直接加载，加载失败时显示占位提示。支持正文中的行内和独立图片语法，不支持引用式图片及 callout/列表内图片。
- 锁定面板状态存在浏览器 localStorage，换浏览器/清缓存后重置。
- 顶栏标题区拖动整个 DSH 窗口只在**桌面版 App**（Electron 无边框窗口）生效；浏览器 Web GUI 会忽略 `-webkit-app-region`。
