# 使用与开发指南

[返回 README](../README.md) · [版本记录](CHANGELOG.md)

本页保留完整的操作说明、文件行为与开发细节。想先了解产品，请看 README。

把 Obsidian 的「进行时」文件夹，变成 DSH 左侧栏入口的一面淡色便签墙（dsh-obsidian-memo）：快速新建、阅读/编辑、卡片内图片预览、四种性格的 AI 评论、归档、到项目、一键在 Obsidian 打开，全在一个面板里完成。读写 md 文件与新建图片附件，Obsidian 仍是唯一的数据主人。

## 它长什么样

```
┌─ DSH 侧栏 ─┐┌─────── Obsidian MEMO v0.18.5 ──────────┐
│ 会话       ││ 120 张便签                    [日期][子文件夹][排序][⚙] │
│ 插件       ││ 主空间   日记   收件箱   项目   ＋    …                │
│ 📌 便签    ││ ┌──────────┐ ┌──────────┐ ┌───────────┐        │
│ 📌 便签    ││ │WORKING_NOW│ │ 无 tag   │ │🚧长期     │        │
│ 自动化任务 ││ │宋体加粗标题│ │标题      │ │标题       │        │
│            ││ │浅一档正文  │ │正文      │ │正文       │        │
│            ││ │ 评论…     │ │          │ │评论…      │        │
│            ││ │[图][图]＋3│ │          │ │[图][图]   │        │
│            ││ │😈✨🧭😇 | 复制 ↗ │ └──────────┘        │        │
└────────────┘└─────────────────────────────────────────────────┘
```

- **工作空间（0.18）**：顶栏第二行是标签栏。第一个「主空间」就是设置里的**默认工作空间**；点右侧加号把仓库内任意可见文件夹挂成标签，点进去只显示该文件夹及子树的便签。挂载的目录会随 `state` 一起被 Host 补扫，未挂载的目录不会出现在墙上。所有标签可右键选纸色（8 个预设；便签、tag 背景和阅读抽屉胶囊按最深层已挂载空间取色：父空间改色不覆盖已挂载子空间，子空间改色同步到父视图，未挂载子文件夹继承父空间），自定义标签另可删除（不动文件夹），长按约 0.4 秒可拖动排序，「主空间」固定首位。把卡片拖到任意标签上松手，就把便签移进该目录（6 秒内可撤销）；在当前空间里快速记录，新便签直接落进对应目录。标签列表按仓库路径存在本地（localStorage），不写入仓库或设置 JSON。
- **淡色便签**：界面按便签所属的最深层已挂载工作空间使用浅/深纸色（主空间默认纸白）；Host 摘要仍保留按 tag 稳定分配的默认色作为回退。0.13 把日间纸色整体往白里调（`#FDFAF4` 系）。开启暗色主题时自动换成同色相的深色纸与提亮墨色。
- **便签标题（0.16.8）**：设置 →「便签」页可选三种来源——**文件名**（默认，保持旧行为）、**正文首行**、**第一个一级标题**。正文模式把标题写进正文，阅读时不重复显示标题行，文件名按模板自动生成（`{title}`/`{date}`/`{time}`/`{timestamp}`，默认 `{date}-{time}`）。标题用宋体加粗（Songti SC 栈）。
- **正文预览**：无图时按标题长短显示最多 7 行，正文够长时至少为它留两行，并在卡片底部多留一点空白。预览保留换行和列表编号；普通项目是灰色小圆点，已完成待办是紫色实心小圆点，未完成是浅紫色实心小圆点（50% 不透明度）。没有正文就把可用空间留给标题。正文与卡片摘要统一 80% 不透明度。
- **版本与署名**：面板标题旁只显示 Host 从 package.json 下发的完整版本号；设置抽屉的「管理与关于」以单行浅色小字显示 GitHub 链接与 by cavenzhong。
- **卡片图片预览**：正文里的图片（`![](…)` / `![[附件]]`）不需要进阅读模式，直接在卡片**左下角、贴住卡片底部**以 64×64 正方形缩略图预览；最多 3 张，超出的显示淡色 `＋N`。缩略图懒加载（并发 ≤3）、失败静默占位、按内存预算缓存，卡片高度仍是 208px；有正文时至少留一行空间，标题短则多显示几行，没有正文时标题可用到图片上方。**只要卡片操作菜单出现（悬停/聚焦整张卡片），图片预览就统一隐藏**，移出后恢复——不再区分鼠标是否停在 emoji 上。
- **阅读**：单击卡片从右侧推出约 1/3 宽的面板看全文（正文块 + PROJECT），面板宽度可拖拽调整；未锁定时便签墙也会为右侧面板自动避让，拖宽或缩放窗口时同步重排，关闭后恢复全宽；评论固定贴在面板下方的独立区域，正文怎么滚都不影响。抽屉标题分割线下方有**操作条**：左侧依次为归档 / 到项目 / 删除 / 复制全文四个线图标，悬停或聚焦时显示上方文字提示；右侧是紫色的「在 Obsidian 打开」图文按钮，两者同一行。底部评论区右侧保留 AI emoji 按钮，旁边有浅色「AI 评论」提示，悬停显示横排预设名。便签卡片在阅读时不显示操作菜单，操作都收在这里（锁定/未锁定都一样）。
- **标题模式（0.16.8）**：设置 →「便签」顶部有三张带插画的大选择卡；选「文件名」时提前提示特殊字符与 240 字节限制，选「正文首行 / 一级标题」时展开文件名模板、token 按钮与实时预览。切换模式会重扫并刷新整库标题，但不会改已有文件名。
- **评论区（0.16.7）**：评论区上边线可上下拖动调整高度（最小 96px，最大 `min(72%, 抽屉高 - 260px)`，给正文留至少 140px），双击恢复默认并记住选择；点击标题或左侧箭头只折叠评论列表，仍可使用 AI emoji 按钮；没有评论时不显示计数，并自动折叠（按钮禁用），有评论才恢复你拉好的高度。展开/折叠状态会记住。卡片上只显示评论的 emoji + 标题 + 加粗条数，不显示正文，点卡片进入面板。每条评论右上角的删除按钮会同步删掉源 md 里的 callout，5 秒内可撤回。
- **编辑**：在抽屉里双击标题或正文进入编辑态；标题输入框随内容自动折行和增高；超出面板时可纵向滚动，底部保存和取消按钮始终可用。正文编辑原始 Markdown；切出插件再回来会恢复同一篇、未保存的修改、光标或选区及滚动位置，不会自动写回。文件名模式下点「保存」同时保存标题与正文，重名时拒绝覆盖。正文模式下标题框与正文里的标题行双向同步，保存只写正文、不重命名文件。
- **锁定面板**：抽屉右上角有锁定按钮（0.13.9 起图标从锁改成**图钉**）。锁定后便签变成真正的右侧面板，与便签墙左右并排、不再互相遮挡；**锁定态不显示关闭按钮**（只留锁定/解锁，Esc 可关），解锁后关闭按钮恢复。锁定状态记住。**锁定面板再进入时不隐藏**：切换面板/重进会恢复上次打开的那篇便签；若它不在当前日期筛选里（或已被归档/改名），自动打开当前筛选排序后的第一篇。
- **阅读勾选**：阅读模式下可以直接勾选或取消任务项，写回原 Markdown 的 `[ ]` / `[x]`，保留原换行和 frontmatter。若内容已被外部修改，会提示刷新后再操作。
- **图片与分界线**：阅读模式显示 Markdown 分界线、`![说明](https://…)`、相对路径图片和 `![[附件]]`。本地图片先从便签相对路径、仓库相对路径查找，Obsidian 裸附件名还会在仓库内查找；重名附件需写完整路径。
- **子文件夹开关**：顶栏的 folder-tree 图标控制主空间是否显示默认工作空间子文件夹里的便签（默认显示）；关闭后主空间只保留顶层 md，自定义工作空间仍包含子树。状态写进设置，重启后保持。所有顶栏 icon 的选中态统一为**浅紫底 + 紫色图标**（日期筛选/子文件夹/锁定/排序/设置）。
- **排序**：默认按文件创建时间（新→旧，菜单第一项）；右上角排序按钮可切换创建时间正序、最近修改、标题。macOS 本地便签在插件内修改后保留创建时间，想让刚改过的便签排在前面可切到「最近修改」。
- **日期筛选开关（0.14）**：顶栏操作区第一个日历图标，点亮按当前范围筛选，熄灭显示全部；与子文件夹图标等宽，不再显示小三角。鼠标悬停显示今天／3 天／本周／本月菜单，移出关闭；键盘可用 ↓ 打开菜单，Esc 关闭。菜单保留「日期截止按真实时间」选项，范围与开关状态继续记住。
- **底部快速记录（0.14）**：透明磨砂胶囊浮在便签墙下方，背后以白色到透明的渐变隔开卡片；深色主题自动换成深色渐变。输入想法作为标题，按 Enter 创建；文件名模式下标题成为新 `.md` 的文件名，正文模式下标题写进正文、文件名按模板生成（重名自动加 `-2`）。面板空白处（无焦点）按 Tab 先聚焦标题，按钮/卡片/输入框上保持原生 Tab 顺序；标题内再按 Tab 展开带分割线的正文区，文字更小、更淡，并自动聚焦；正文按 Shift+Tab 返回标题修改，保留正文草稿，再按 Tab 可回到正文；正文可正常换行，⌘／Ctrl + Enter 创建。未展开时仅显示淡色 `Tab 补充正文` 提示；正文删空后自动收起为标题态（空正文 Backspace 或失焦也会收起，Esc 退出输入焦点）。正文区右下角显示淡色 `⌘ Enter 提交` 提示，焦点描边更清晰。重名、文件名过长或提交失败时保留草稿与图片，成功才清空。新建时沿用 Obsidian Default Template 为当前文件夹配置的模板 meta（`{{date}}`/`{{time}}`/`{{title}}` 变量按插件语义替换；模板配置损坏或不可读时按无模板新建），带正文或图片也会保留。阅读视图保留有序列表数字与无序列表圆点。
- **拖拽与删除（0.15）**：拖动卡片时输入岛切换为「归档 / 到项目 / 删除」三列操作栏，输入岛暂时隐藏。拖到归档后可选已配置目录，拖到项目会展开新建和已有项目的菜单，删除在放手时执行；原位置保留空虚线框，拖动卡片的宽高均缩为原来的 1/3，实色动作提示固定在预览上方且层级更高，底部渐变随目标变色，操作格高亮贴合外栏圆角。卡片菜单在 AI 评论下方仅保留「复制 / 在 Obsidian 打开」，归档与到项目从拖拽栏或阅读面板进入；聚焦卡片或阅读面板时按 ⌘／Ctrl + Backspace 可删除。md 与独占图片成组进入库内 `.trash/MEMO-…` 文件夹，5 秒内撤回；共享图片保留，冲突时拒绝覆盖。到期后文件保留，可按组内 `restore.json` 的原路径手动移回，不自动清空；已有回收文件不会被清理。macOS Finder 按 `⌘ + Shift + .` 可显示隐藏文件夹。
- **归档**：在设置 →「便签」的归档专栏中选择方式。可归档到便签当前目录下的文件夹（默认名「归档」，可自定义），也可归档到指定根目录并按默认工作空间/仓库结构保留子目录。将卡片拖到归档按钮时，跟随预览的提示会显示目标位置；放手后立即移动，成功后可撤销。
- **输入岛（0.15）**：Enter 统一聚焦输入岛，输入岛内输入和右侧正文编辑保留原行为，输入法组合态不拦截；卡片悬停或聚焦时也不会再打开详情，Esc 退出焦点。标题自动折行显示全文。向下超过一屏后上方出现圆形 ↑ 返回顶部。浮动或钉住面板都不遮挡输入岛与拖拽栏。从侧栏或菜单切换到本插件后，面板会自动接住键盘焦点，直接按 Enter 就能进入输入岛，不必先点一下面板。
- **新建图片（0.14）**：在输入栏粘贴或拖入图片，或点左侧加号多选 PNG／JPEG／GIF／WebP；左侧正方形预览默认叠放，悬停或键盘聚焦后展开，停留 600ms 在上方显示最大约 260×220px 的完整图浮窗，可逐张移除。最多 8 张，保存后的单张上限 8 MB、合计 16 MB。在设置的「图片处理 → 图片文件夹」可手填或选择仓库内目录，相对路径按仓库解析，不存在时自动创建；不能选仓库内以 `.` 开头的隐藏目录（Obsidian 不索引）；留空仍保存在默认工作空间的 `_attachments/`。目录调整仅影响之后保存的图片。Markdown 使用仓库相对图片 wikilink，便签归档后仍能在 Obsidian 找到图片。
- **图片处理（0.14）**：设置在「便签」页下半部分的「图片处理」专栏，默认勾选自动压缩为静态 WebP，质量 **70**、最大边长 **2048px**。可调整质量 1–100、最大边长 256–8192px；按比例缩小、不放大小图。取消勾选则保留原始字节、格式及动图。参数在创建时生效，修改设置后待提交的图片也按新参数处理。压缩前单张最多 32 MB、合计 64 MB；压缩完成后按上述保存上限检查。压缩失败保留草稿并提示原因。

- **AI 评论（0.13）**：卡片 hover 后，**所有 emoji 预设平铺在操作区第一行**（不折叠）；鼠标悬停某一枚时，在它上方浮出文字标题告诉你这个 emoji 是什么（如「毒舌」）。点击后后台用默认模型生成，以 Obsidian callout 追加到 md 末尾，卡片上同步显示。若这张便签已有同款评论，会先问「要再生成一条吗？」。分割线下方是「复制 / 在 Obsidian 打开」。卡片评论条只按类型显示 `emoji + 标题 + 条数`；右侧评论卡片可直接删除，源 md 同步移除，5 秒内可撤回。
- **四个 AI 人格预设**：
  - 😈 **毒舌**：尖锐黑色幽默，要妙、像金句，但不为刻薄而刻薄；专业问题玩笑后会提醒找专业人士；写作类则切换成大哥口吻给一句真正有用的话。
  - ✨ **另一面**：从一个你完全没想过的角度切入，再回到人本身，说中情绪但不空洞共情。
  - 🧭 **落地**：务实判断，惜字如金——一句话结论 → 2–3 条证据链（标明推测）→ 最省力的下一步与验证信号。
  - 😇 **真心话**：贴心伙伴，接住状态、指出你做对的一个小地方，给一句不带压力的鼓励和一个轻起手。
  - 旧版本的 4 个默认预设（洞察/延伸/风险/下一步）如果原样没改过，会自动迁移成这 4 个；你改过的预设不动。
- **归档**：在设置 →「便签」选择“当前目录”或“指定目录并保留结构”；拖到归档按钮即按所选方式移动，顶部小浮窗 6 秒内可「撤销」。
- **项目跟踪**：拖拽菜单先列出「新建项目」和已有项目（按更新时间排序）。新建默认先等待 3 秒，可取消；分析期间只有小提示，AI 返回结果才弹出确认框，确认后生成 `<项目名>-项目.md`；已有项目不弹窗，经过可取消的 3 秒确认后用补充提示词更新进度。便签不移动，只通过可配置的 `PROJECT` frontmatter 双链关联。
- **在 Obsidian 打开（0.13.8 / 0.13.9 微调）**：卡片操作行「复制」的**右侧**（同一行、右对齐）是「在 Obsidian 打开」：一枚转发 icon + **紫色高亮**加粗文字；右侧面板的操作条也保留同款按钮，与归档 / 到项目 / 删除 / 复制全文四个线图标同一行、靠右。点击后由 **Host** 调系统打开器打开 `obsidian://open?path=<便签绝对路径>`（macOS `open` / Windows `start` / Linux `xdg-open`）；DSH 外壳只放行 http(s) 外链，所以自定义协议必须走 Host。只允许打开仓库内已存在的文件；没装 Obsidian / 没有打开器时用 toast 报原因，不会碰任何文件。
- **0.13.9 小细节**：卡片没有正文时**不再显示「（暂无正文）」占位**；Obsidian 行尾 / 段中的 block id（`^qa-daily-preview-1e5t8lm` 这种）在正文与摘要里隐藏，且**只去掉锚点本身、不影响锚点后面的文字**；顶栏「Obsidian MEMO」标题区域（含下方的目录小字）在 **DSH 桌面版**里可以直接按住拖动整个窗口（Web GUI 里浏览器会忽略该行为），右侧按钮区仍然正常点击。**0.17 起同一块顶栏也支持单击**：标题、目录、留白和按钮间隙单击（位移小于 3px）会收起未锁定的右侧抽屉，按住移动超过 3px 则移动窗口且不误关。
- **动态加载（0.13.8）**：便签墙**首屏只渲染 50 张**，滚到接近底部（提前约 320px）自动补下一批 50 张；补批时墙底部出现**简约三点加载动画 + 「加载中…」淡字**。排序/日期筛选变化会回到首屏 50 张。数据仍是 Host 一次 `state` 下发（几十 KB），这里分批的是**渲染 / DOM**，不是网络请求——对几十张的库感知很小，几百张以上时明显降低首屏渲染与滚动压力（详见「性能与后台开销」）。

## 安装

```bash
# 在 DSH 里用工具安装（等价于 Plugins 页的“安装”）：
#   plugin_manager  action=install_bundle  target=link:/绝对路径/dsh-obsidian-memo
```

安装后左侧栏末尾出现便签图标。首次点击面板会提示去设置里选目录。

### 可选：改代码即时生效（开发用）

在 `~/.dsh/profiles/<profile>/cordis.patch.yml` 的 `hmr` 条目里加上本插件目录：

```yaml
- id: hmr
  name: "@deepseek-ai/dsh-hmr"
  config:
    root:
      - "."
      - /absolute/path/to/dsh-obsidian-memo
```

之后改 `lib/` 下的 Host 模块会自动重载。浏览器开发先运行 `pnpm dev`，修改 `src/client/` 后会自动更新 `lib/client.js`，再由 Harness HMR 重载。

## 首次配置

从便签面板右上角齿轮打开设置。设置分为「文件夹」「便签」「项目」「AI」「管理与关于」五个标签。

「AI」页先是一块独立的 **项目 AI**：项目 AI 引擎（模型）与项目更新 token 预算；下面是评论 emoji 的角色与预算。模型列表来自 DSH 里已启用的模型服务（`ctx.llm.listProviders()` + 每个 provider 的 `listModels`），默认跟随 DSH 当前默认模型。

| 字段 | 说明 |
|---|---|
| 仓库根目录 | Obsidian 仓库绝对路径（如 `…/Documents/2024仓库`） |
| 默认工作空间 | 主空间对应的目录（如 `⛳️进行时&未整理`），必须是仓库子目录；其它工作空间可挂载仓库内任意可见目录 |
| 项目索引目录 | 新的 Project 索引 md 直接建在这里，不再为每个项目建立子文件夹 |
| 便签归档 | 可归档到每个便签所在目录下的命名文件夹（默认「归档」），或指定一个归档根目录并映射默认工作空间/仓库结构 |
| 图片处理 / 图片文件夹 | 自动压缩为 WebP（默认勾选），质量 1–100（默认 70），最大边长 256–8192px（默认 2048）；取消勾选保留原图。图片文件夹保存新建图片，留空 = 默认工作空间的 `_attachments/`，必须是仓库内目录且不能是以 `.` 开头的隐藏目录 |
| Emoji 与提示词 | 横向 Emoji 标签切换角色，末尾固定加号；所选角色编辑字形、名称、callout、提示词与预算。项目提示词折叠在下方。 |
| AI 预算 | 每枚 emoji 行内一个下拉：**低 / 中 / 高 / 自定义**（低 = 不思考·2048、中 = 低思考·4096、高 = 高思考·8192 tokens，默认高）。选「自定义」时再露出「思考档位 + 输出上限」两个字段；「AI」页的「项目 AI」区块下有同款控件，控制项目更新。 |
| 项目提示词 | 新建项目时生成项目文档的提示词 |

配置默认在用户目录 ~/.config/dsh-obsidian-memo/config.json（Windows 使用 %APPDATA%，尊重 XDG_CONFIG_HOME）。首次读取旧 data/settings.json 并迁移，原文件保留。DSH_STICKY_NOTES_SETTINGS 可固定位置。设置中的「管理与关于」可打开 JSON、显示所在文件夹、重载、直接选择并加载已有 JSON，或另存到自定义位置并记住选择。另存使用已保存配置，不覆盖已有目标；加载/重载会替换当前草稿。文件夹在 JSON 中保存为仓库相对路径，外部修改会自动加载，配置损坏保留文件及上次有效值；并发旧草稿保存会被拒绝。

先选仓库，之后默认工作空间、项目、图片和指定归档根目录共用一个文件夹下拉组件（工作空间的加号也复用它）：顶部加号在仓库中新建文件夹，其下为系统选择、搜索和最近使用记录。选择或新建的文件夹必须位于仓库内；隐藏目录和越界符号链接不可选。

日常删除继续使用仓库 .trash 和 5 秒撤回。设置内单独提供「在 Finder / 文件管理器中显示」与「移至系统垃圾桶」：确认后将整个 .trash 交给系统回收 API，包含 Obsidian 放入的内容，之后从系统垃圾桶恢复；不会清空系统垃圾桶。撤回窗口内拒绝清理，失败保留回收文件并提示原因。

## 列表的阅读与编辑

- 阅读模式：悬停普通圆点或待办项，左侧出现三点抓手。同一连续列表内可在同层级的圆点和待办之间拖动排序，目标上半部/下半部对应前/后。拖动时整项压暗，三点留在原位。
- 编辑模式：**Cmd/Ctrl+L** 循环无标记、圆点、未完成、已完成；有序项保留编号。**Cmd/Ctrl+↑/↓** 与同层级项换位；**Cmd/Ctrl+←/→** 调整缩进。按住 Cmd/Ctrl 且当前列表行可以换位时，底部显示这些快捷键；其它时候照常显示保存与取消提示。

## 它怎么碰你的文件

- **只写仓库内的 Markdown 和新建图片附件**：默认工作空间、挂载工作空间、归档目录、项目目录、图片文件夹的用户路径与真实位置都必须落在仓库内；便签操作接受仓库内任意非隐藏的 md；图片文件夹不能是隐藏目录；目录符号链接也要校验，新建路径检查最近的已有父目录。
- **frontmatter 原样保留**：渲染永远丢弃 meta；只有「到项目」会改源便签的 frontmatter，且只写 `PROJECT` 一个键，已有非空值时不覆盖。项目文档本身的「当前概况 / 进展记录」由项目流程写入，不碰源便签正文。
- **原子写**：已有文件先写临时文件再 `rename`；新建便签先保存附件，再以独占硬链接发布完整 Markdown，拒绝覆盖同名文件。发布失败会清理本次附件与临时文件。
- **保存与评论**：保存只替换 frontmatter 之后的正文；评论追加在文末，都是纯文本拼接，不重排 frontmatter、不规范化格式。
- **列表排序**：阅读态排序使用打开时的内容 revision；外部修改后排序会冲突而不会覆盖。移动时保留 Markdown 列表标记、层级、子项、frontmatter、空行、评论和原行结束符。
- **与 Obsidian 并发**：编辑保存带有打开时的内容版本，若期间被 Obsidian、AI 评论或其他编辑改变，会拒绝保存并保留草稿。没有跨进程文件锁；版本检查和写盘之间的极短外部写入竞争仍可能发生。
- **不渲染 meta**：卡片标题取 md 文件名，文件内容作为正文，callout 作为评论；行尾 block id（`^qa-daily-preview-…`）不显示，且不影响锚点后面的文字与行内代码里的 `^`。

## AI 评论与项目

- 评论用 DSH 当前默认模型（`agentDefaultModel`）；项目可在设置 →「AI」→「项目 AI」单独指定模型。都通过 Host 的 `ctx.llm` 调用：**不占用任何会话、不写对话日志**。
- 生成是异步 job：点击后立即返回，面板显示「正在写评论…」，完成后写入 md 并自动刷新；失败会在 toast 里给出原因。
- **AI 预算（0.13）**：DeepSeek 的 `max_tokens` 是总输出预算，思考 token 也算。默认「高」档（`high` / 8192）就是给思考留足余量；如果模型把预算全用在思考上、正文没写出来，会弹一条带「去设置 / 知道了」的提示，点「去设置」直接打开设置抽屉调档。评论撞上上限但已有正文时会写入并提示；项目若只收到半篇则两份文件都不改。
- 评论 callout 形如：

  ```markdown
  > [!quote] 😈 毒舌 · 2026-11-04 10:30
  > 这条想法真正的钩子在……
  ```

### 项目文档怎么读、怎么补充

打开项目先读顶部的「当前概况」。它回答事情是什么、现在到哪、依据是什么，以及下一步要做什么或卡在哪里。底部的「进展记录」保留当时的判断，所以旧的“准备上线”可以留在历史里，而不会继续被当成现状。

```markdown
# 支付上线

## 当前概况
本轮验证支付链路。原定上线，但因[[进行时/回归报告|退款用例仍失败]]已暂停。修复后先复验，再决定发布时间。

## 进展记录
- 11-18：[[进行时/联调记录|联调通过]]，准备上线。
- 11-20：回归暴露退款问题，暂停上线。
```

- 补充时，AI 同时拿到完整项目和这次便签，自行决定改哪些判断、怎样写句内双链；插件不补写引用，也不强制生成「来源」列表。若只有佐证，概况可以不变，历史追加这份证据。
- 想原样保留个人笔记，可放在单独的二级标题（如 `## 我的手记`）下。概况内的文字属于可修订正文；生成时 AI 可以读到手记和旧历史，但不必抄写它们：插件从原文件直接保留这些文字，包括已有的 YAML、BOM 和换行。
- 原验收浮窗直接显示本次变化，例如「支付上线 · 当前状态：准备上线 → 因回归失败暂停」。查看、验收和撤销仍在同一处。验收前撤销可同时还原项目及源便签；Host 重启后不再保留本次备份。
- 旧项目不批量改写。下一次补充时才整理旧概况，把原先置顶的带日期进展按旧到新移入历史。若你自己改过提示词，仍保留你的版本，可在项目设置中恢复新默认提示词。

## 技术架构

- **Host 半**：`lib/index.js` 组合 `lib/host/` 内的配置、扫描、写入、图片、AI 任务与 RPC 服务；`files.js` 统一真实路径边界、内容版本与原子写入，`capture.js` 负责新建便签与附件；`notes.js` / `scan.js` / `settings.js` / `ai.js` / `obsidian.js` 分别负责解析、扫描缓存、设置、模型和系统打开。
- **通道**：Host 在 web server 上注册包内已认证 RPC 前缀路由 `/sticky-notes`，复用 client-connection 的 RPC 信封协议（Client 仍用 `ctx.connection.rpc.call('/sticky-notes', endpoint, payload)`），认证复用 `ctx.connection.requestRejection`。Web GUI 与桌面 App 外壳都走同一条已认证通道，不新开端口、不需要额外的 CSRF 防护。
- **目录选择**：统一使用系统选择器 `pickDirectory`，也可手动输入路径；已移除没有界面调用的目录浏览 RPC。
- **Client 半**：源码位于 `src/client/`，按功能组织组件、hooks、样式与文案；`pnpm build` 生成单文件 `lib/client.js` 供安装使用。`useNotesData` 管请求与轮询、`useNoteEditor` 管抽屉草稿与保存、`useSettingsDraft` 管设置草稿；主面板组合拖拽、AI、筛选、分页与布局模块。所有 state 请求统一按代次接收，迟到响应不能覆盖新状态，未变化卡片复用对象。
- **不注册模型工具、不注入提示词**：除用户主动点评论或到项目外，不产生任何模型调用与会话成本。
- **已知问题与暂缓项**：见 [已知问题](KNOWN_ISSUES.md)（v0.18.0 基准，含触发条件与建议修法）。

## 性能与后台开销

- Host 端 `state` 轮询在真实库（97 篇）实测热响应 3.5–6.5ms、2.4KB；冷启动约 67KB。扫描按 mtime 缓存，内容没变不重读。
- **空闲轮询会自适应退避**：4s → 8s → 12s → … 最长 30s；有变化或你主动刷新/评论/保存时立即回到 4s。面板不可见（切到别的面板/窗口隐藏）时暂停请求，约 15s 才探测一次。
- 便签卡片做了 memo：轮询拿到「没有变化」时面板不会整墙重渲染；有变化时只重渲染变化的卡片。
- **便签墙分批渲染（0.13.8）**：首屏 50 张，触底补 50 张。Host 下发的 notes 只有几 KB～几十 KB（97 篇热响应 2.4KB），所以这一层不减少网络，只减少首屏 DOM/布局与 React 渲染量；没有引入虚拟列表（不卸载已渲染卡片），复杂度最低。120 张左右收益有限，300+ 张时更明显。
- 卡片缩略图：进入视口才加载、同时最多 3 个请求、按约 24MB 内存预算做 LRU，避免一次涌入大量 base64 卡住主线程。
- Host 端对同一设置指纹的并发扫描做了单飞（single-flight），附件名查找有负缓存，避免重复全库遍历。
- 如果仍然遇到 DSH 整体卡死，请先看：① 是否正在大量新增/同步笔记（iCloud 文件下载会拖慢一切）；② 卡死时 CPU 大户是 DSH 的哪个进程；③ 把插件禁用后是否还复现——这能区分「插件开销」与「DSH 自身/HMR」问题。

## 已知限制

- 不做全文搜索、拖拽排序、批量选择。
- **平台**：主要在 macOS 上开发与验证；Windows / Linux 的路径处理与「在 Obsidian 打开」已实现但未实测；移动端没有专门适配，以桌面为主。
- **「在 Obsidian 打开」依赖本机 Obsidian**（macOS `open` / Windows `start` / Linux `xdg-open` 调 `obsidian://open?path=…`）：未安装或未注册协议时会 toast 失败；只对仓库内已存在的文件生效；这个动作不会写入任何内容，打开后由 Obsidian 自己读取文件。
- 编辑态保存是显式按钮（或 Cmd/Ctrl+S），退出编辑态会丢弃未保存修改。
- 归档撤销窗口 6 秒（token 服务端保留 10 分钟）；撤销前若原位置已有同名文件则拒绝恢复。
- 面板以轮询感知外部修改，不是实时监听；空闲时按 4–30 秒间隔检查外部变化，也可以手动刷新。
- 手动改 `package.json` 或依赖不会被 HMR 检测；改 Host 模块或前端生成文件需要配置 hmr root 才会即时生效，前端源码配合 `pnpm dev`。
- 本地图片限仓库内的 PNG/JPEG/GIF/WebP/SVG/AVIF，单张不超过 8 MB；卡片缩略图只加载 ≤1.5 MB 的图片（超出的卡片上显示淡占位，进阅读模式仍可看）。卡片预览只覆盖正文图片，不覆盖 callout/列表内的图片。
- 不读取仓库外的符号链接目标；网络图片由浏览器直接加载，加载失败时显示占位提示。支持正文中的行内和独立图片语法，不支持引用式图片及 callout/列表内图片。
- 锁定面板状态存在浏览器 localStorage，换浏览器/清缓存后重置。
- 顶栏标题区拖动整个 DSH 窗口只在**桌面版 App**（Electron 无边框窗口）生效；macOS 桌面版由插件自己用 `window.moveTo` 移动窗口，Web GUI 会忽略。单击收起右侧抽屉在 Web GUI 和桌面版都可用。
